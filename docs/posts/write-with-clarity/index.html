好的英文表达，从一句清楚的话开始

先写清楚想说什么，再考虑怎样说得更自然。简单的词，也可以组成有力量的句子。

3 分钟阅读ENGLISH LEARNING NOTES

这是一篇示例札记，用于展示英文例句、段落和练习的排版。

先把一个想法说清楚

开始写作时，可以先问自己：我希望读者知道什么？用一句简单的英文回答这个问题，再决定是否需要补充原因或例子。

I enjoy reading because it helps me see things differently.

我喜欢阅读，因为它让我从不同的角度看待事物。

具体一点，读者更容易理解

如果写下了“阅读很有帮助”，可以继续补充：哪一次阅读、哪一个故事，带来了什么变化？具体的经历能让表达更清晰。

修改时，检查三个问题

  • 这句话是否表达了我真正的意思？
  • 读者能否知道代词指的是谁或什么？
  • 有没有一句话装进了太多不同的想法？

选一段自己的旧作文，保留意思，用更简单的方式重新写一遍。然后比较两版，看看哪一版更容易读懂。

读完之后，试着用自己的话说一遍。
